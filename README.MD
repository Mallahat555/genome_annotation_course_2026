2. EDTA: Building transposable elements library

        Input:  1. Genome Assembly LJA FASTA file

                2. Arabidopsis Thaliana reference genome: TAIR10 CDs

        Does:   1. Builds a customized, non-redundant transposable elements (TE) library from scratch,
                   performs whole-genome annotation.

                2. Filters out gene-derived sequences so they aren't mistakenly classified as transposable elements.

                3. Incorporates RepeatModeler to find divergent or complex TE families for higher sensitivity.

                4. Maps the final TE library back onto the genome to generate coordinates and classification maps of
                   all TEs.

                5. Retains complete, intact LTR retrotransposon elements.

        Output: 1. Final TE Library (*.TElib.fa): A high-quality, non-redundant library of consensus transposable  
                   element sequences discovered in your genome. 

                2. Genome Annotations (*.anno.gff3): A GFF3 file containing the precise chromosomal coordinates,  
                   classifications, and structures of all annotated TEs across the genome.

                3. Classification & Summary Files: Various sequence files and summary tables categorized by TE   
                   superfamilies (e.g., LTR, TIR, Helitron).

        Run:    sbatch scripts/02_run_EDTA.sh

3. TEsorter: Transposable Elements Classification

        Input:  From EDTA run:

                1. Intact LTR FASTA files:
                   This file contains DNA sequences of every high-confidence, 
                   full-length LTR retrotransposon discovered in A. Thaliana genome.
        
                2. Intact GFF Files: 
                   A map file showing Which chromosome or scaffold LTRs are on:
                   coordinates: exact start and end positions 
                   + or - : Which DNA strand it is on
                   Structural details: positions of the Long Terminal Repeats and internal domains

                3. Database (rexdb-plant): 
                   The reference database used by TEsorter to classify plant LTR retrotransposons 

        Does:   1. Classifies the intact LTR retrotransposons by identifying conserved protein domains 
                   such as reverse transcriptase, integrase, and RNase H, and grouping elements into specific 
                   lineages e.g., Copia or Gypsy families.

        Output: 1. Local Working Files: 
                        intact_LTR.fa 
                        intact_LTR.gff3
                
                2. TEsorter Classification File: 
                   Tab-separated output files (.cls.tsv or .dom.tsv) detailing the superfamily,
                   lineage, and structural domain organization for each intact LTR retrotransposon element.

        Run:    sbatch scripts/03_run_TEsorter_full_length_LTRs.sh 

4. LTR itentity

        Input:  R Script 04_full_length_LTRs_identity_copy.R with:

                1. The raw GFF file generated by EDTA 

                2. TEsorter Classification File (cls_file)

        Does:   Measures the sequence similarity between a retrotransposon's two flanking LTRs, acting as a 
                molecular clock to estimate when the element inserted into the genome (with higher identity indicating a more recent insertion).
        
                1. Parses GFF Data: 
                   Loads the GFF, strips out minor subfeatures (like individual repeat regions or 
                   Target Site Duplications) to focus on top-level elements, and uses regular expressions to extract key metrics: element Name, LTR identity (percentage match between the two LTRs, used to estimate insertion time), and element length.

                2. Parses & Merges Classifications:
                   Reads the TEsorter classification file, cleans up the headers,   
                   and merges it with the GFF annotations using the common element Name.

                3. Generates Distribution Plots

        Output: 1. 01_LTR_Copia_Gypsy_cladelevel.png & .pdf: 
                   Detailed clade-level breakdown plots for Copia and Gypsy superfamilies.
                
                2. 02_LTR_Copia_Gypsy_global.png & .pdf: 
                   Clean, side-by-side comparative histograms for all Copia and Gypsy elements pooled together.

        Run:    sbatch scripts/04_run_R_length_LTRs_identity.sh
                  it controlls running R script: scripts/04_full_length_LTRs_identity_copy.R in the container
