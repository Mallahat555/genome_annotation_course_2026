11. run maker

        Input:      Genome Assembly: FASTA file of the target genome
                    Transcriptomic Evidence: Trinity RNA-seq assembly
                    Protein Homology Evidence: Plant protein databases (TAIR10 and UniProt Viridiplantae reviewed proteins).
                    Repeat Library: Custom transposable element library generated by EDTA along with repeat protein databases.
                    Gene Prediction Settings: Augustus gene predictor configured for Arabidopsis (arabidopsis), with est2genome=1 and protein2genome=1 enabled.
                    Control Files: MAKER configuration control files (maker_opts.ctl, maker_bopts.ctl, maker_exe.ctl, maker_evm.ctl).

        Does:       MAKER is a genome annotation pipeline that masks repeats, aligns transcript and protein     
                    evidence, performs gene prediction, and synthesizes everything to generate consensus structural gene models.


        Output:    MAKER Annotation Results:
                        GFF3 Files: Standardized gene annotation files containing the final gene models and evidence alignments.
                        FASTA Files: Extracted transcript and predicted protein sequences.
                        Intermediate Data (theVoid/ & datastore): Master data stores containing intermediate alignment and prediction files for restarting or updating annotations.

        Run:    copy the four templates from:

22. Quality Assessment of Gene Annotations - BUSCO

        Inputs: takes MAKER filtered fasta files with longest protein and transcript sequences from step 20:
                protein=assembly.all.maker.proteins.fasta.renamed.fasta.filtered.fasta
                transcript=assembly.all.maker.transcripts.fasta.renamed.fasta.filtered.fasta 
                
        Does:   Selects longest isoforms for proteins and transcripts, reason:
                MAKER (and alternative splicing/gene prediction) often generates multiple isoforms for a single 
                gene (e.g., -RA, -RB, -RC), which share most of the same exons and functional domains.
                Extracting the longest isoform per gene provides a complete, representative model for each locus, allowing BUSCO to evaluate single-copy orthologs accurately without alternative transcripts artificially inflating duplicate scores.

        Output: fasta files with the longest most representative isoforms of proteins and transcripts ready for 
                BUSCO.
     
        Run:    sbatch scripts/21_run_BUSCO_on_MAKER.sh

29. Process Pangenome:
        Input:     Pangenome File: TAIR10_pangenes.txt.gz (located in your GENESPACE output directory), 
                   containing gene mappings, coordinates, and reference-relative positions using TAIR10.

        Does:   1. Read the pan-gene table. Load pangenes/TAIR10_pangenes.txt.gz, generated by GENESPACE, which links
                   genes across accessions to pan-gene entries using TAIR10 as the reference and records their positions,
                   orthogroups and assignment flags.
                2. Count copies in each accession. Count genes for each pgID (the identifier of a positional pan-gene entry
                   linking corresponding genes across accessions) separately in each accession.
                3. Summarise presence and plot its frequency. Classify entries as core (present inall accessions), accessory
                   (present insome but not all), or accession-specific (present inone accession) and save
                   plots/pangenome_presence_frequency.pdf. 

        Output: 1. process_pangenome/plots/pangenome_presence_frequency.pdf: Bar chart showing how many pan-gene entries are 
                   shared across different numbers of accessions.
                2. process_pangenome/plots/copy_variable_core_comparison.pdf: Heatmap displaying copy-number variations across 
                   accessions for top copy-variable core genes.
                3. process_pangenome/tables/focal_TAIR10_genes.tsv: Detailed gene position table comparing your focal genome 
                   against TAIR10.
